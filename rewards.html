This page shows on-chain FTSOv2 reward receipts for any Flare wallet (receipts since 2026-07-28; FSP claims expire after ~91 days, so this covers effectively all live claiming): amounts, dates, and transactions, with USD values from CoinGecko's FLR/USD daily close (UTC). It contains no tax, investment, or financial advice and does not characterize any amount — how these records are treated is a question for your own professional adviser. Receipt times are derived from block anchors (accurate to within minutes) and used only to select the daily price. Live delegation and autoclaim status are read directly from the Flare network at lookup time. Data refreshes daily.
